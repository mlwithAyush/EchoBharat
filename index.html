03 — THE PARADIGM SHIFT

Rethinking What a Complaint Means

Old model:

A Complaint = A Problem

Our insight:

A Complaint = An Allegation

ALLEGATION

The Allegation

A single user report is just a starting point and is inherently unverified.

CORROBORATION

The Corroboration

Independent observations from distinct users act as corroborating witnesses.

VERIFICATION

The Verification

Objective supporting evidence (photos, metadata) transforms the allegation into a corroborated civic issue.

"We are not building a truth detector. We are building an evidence engine."

04 — THE SOLUTION

An Accountability Layer

Not a generic portal. Not a government database. An AI-assisted civic issue verification system.

INPUT

Citizen Report

User submits complaint with description, location, and optional evidence.

PROCESSING (AI)

AI Extraction → Similarity → Clustering

NLP extracts category, location, time. Similarity detection groups related reports.

VALIDATION

Corroboration → Evidence Uploads

Independent reporters and objective evidence validate the issue cluster.

OUTPUT

Status → Action → Resolution

Deterministic status assignment, action tracking, and post-resolution citizen check.

09 — ARCHITECTURAL PHILOSOPHY

AI Assistance + Transparent Rules

AI's Role (Heuristics)

  • Complaint text extraction
  • Semantic categorization
  • Similarity assistance (NLP)
  • Automated summarization
  • Spam/abuse moderation

Conventional Logic (Determinism)

  • Location proximity mapping
  • Category matching
  • Time overlap validation
  • Evidence cross-referencing
  • Reporter independence rules

"AI organizes the data. Deterministic logic validates the evidence. AI does not determine 'truth.'"

CREATE TABLE reports (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  description TEXT, category TEXT,
  location TEXT, report_time TIMESTAMPTZ,
  user_id TEXT, photo_url TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);
CREATE TABLE issues (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  title TEXT, category TEXT,
  status TEXT DEFAULT 'UNVERIFIED',
  total_reports INT DEFAULT 1,
  independent_reporters INT DEFAULT 1,
  evidence_uploads INT DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);
